# listening-drill（英语精听 v2）

盲听逐句精听（英文音色合成朗读，词级三色判分）→ 错词归因成卡（选择填空入题库，SM-2 复习）。
教学主线：**可理解输入 i+1 → 盲听逐句精听（多遍/慢速）→ 对照文本精准纠错 → 错词归因成卡 → SM-2 复习**。
v2 定调（2026-09-26，用户反馈「功能不可用/错乱+交互差」重设计）：**句子是「过程」，错词卡与材料文档才是「资产」**。

## 设计要点

- **会话模型（v2）**：材料元数据按会话登记 plugin_kv `session`（sentences 内嵌），历史可达——
  v0.1.0 只记 latest 一条且库内选材排除 `英语精听/`，旧材料建新会话后永远不可达（实证缺陷）。
  同名标题追加时间戳防覆盖（v0.1.0 覆盖文件导致旧句题残留成孤儿）。
- **听写句不入题库（v2）**：句题 id=`ld-<docId8>-<序号>` 会话内即时投影，recordAttempt 题库轨因无库行
  自然跳过——复习队列从「N 句淹没」收敛为「材料文档 SM-2 到期重听 + 错词卡」（v0.1.0 逐句 insertQuestion，
  材料 20 句即 20 张复习卡，清偿分母被冲爆）。作答史/错词重建读 practice_attempts（文档锚点权威流水）。
- **判分**：`dictation` 题型注册于 `core/knowledge/question-types.ts`；词级 LCS 对齐（命中/听错/漏听三色）
  core 唯一实现；大小写/标点忽略，缩写按字面，全命中且无多写才算对。
- **听觉链路（v2 平台修复）**：英文内容自动英文音色（`pickCloudVoice`，中文音色读英文发音失真属教学级错误）；
  `speakVoice` 设置真实生效（此前零消费方）；合成失败可见化（`onSpeakError` → 听写区内联 Alert，
  此前云端失败静默无声）。播放唯一实现=主窗 voice-player 单例，本插件零播放器代码。
- **错词成卡**：错词表行内一键「听不出·成卡 / 不认识·成卡」，「拼错」走表单三选；一词一卡（题干=挖空原句）；
  插件层按词去重（content_hash 含随机洗牌的 options_json，宿主去重对填空卡永不命中——v0.1.0 起潜伏 bug）。
- **AI 生成档位（v2）**：日常三档（入门 A2/进阶 B1/挑战 C1）+ 考试四档（雅思·生存对话/雅思·学术讨论/
  托福·校园对话/托福·学术讲座），各带 CEFR/句数/题型风格 spec 与推荐话题；标尺回环校准（至多重试一次）。
- **建会话快速返回（v2）**：切句+难度+落盘 <1s；逐句中译后台补全（完成后更新材料文件与会话元数据，
  失败如实落 'failed'），不阻塞精听。
- **三态动线**：会话详情双语对照（听前）→ 听写盲听（练中）→ 判分三色+原文+中译（练后）；
  「📄 原文」行内动作经 open_document 意图在编辑器打开材料文件。
- **材料落盘**：sys-hub「英语精听/」（KERNEL-BOUNDARY 契约子目录）；难度标尺=1 万高频词覆盖率
  （阈值 0.93；词表 `data/wordlist-10k.txt`，google-10000 频序，纯词序事实数据，换源整体替换）。

## 明确不做（v2）

AI 口语陪练 / 音素级发音评测 / 视频字幕注入 / 多词库管理 / 独立统计页 / 跟读对比 / 真实音频导入 / FSRS（复用宿主 SM-2）；
会话删除的声明式确认交互（`deleteSession` 方法已在，待确认 UI 登记 backlog）。
